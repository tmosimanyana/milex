# Milex Farm Website

A responsive website for **Milex Farm**, a Botswana-based farm located approximately 30 km from Letlhakeng.

The site introduces the farm, presents its produce and livestock, explains how customers can place orders, and provides contact and location information.

## Website

- Farm introduction and story
- Seasonal produce and farm-raised livestock information
- Ordering guidance and direct customer enquiries
- WhatsApp-based ordering flow
- Farm services and location information
- Responsive navigation and mobile-friendly layout
- Search and social-sharing metadata

## Built with

- HTML5
- CSS3
- JavaScript

The project uses a lightweight front-end structure and does not require a framework build step.

## Project structure

```
milex/
├── index.html
├── images/
├── scripts/
│   └── main.js
└── styles/
    └── styles.css
```

## Run locally

Because this is a static website, you can open `index.html` in a browser. For a more representative local test, serve the project directory with a local development server.

For example, with Python installed:

```bash
python -m http.server 8000
```

Then visit http://localhost:8000.

## Deployment

Deploy the project directory to a static hosting provider. Make sure the `images/`, `scripts/`, and `styles/` paths remain intact.

## Notes

Farm availability and seasonal produce can change. Customers should confirm current availability and delivery arrangements directly with Milex Farm.
