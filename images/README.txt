PUT YOUR PHOTOS IN THIS FOLDER
==============================
The page finds each photo by file name and tries .jpg .jpeg .png .webp.
If a photo isn't found, placeholder.svg is shown instead.

Current names the page looks for:
  hero (top banner)  hero
  Tswana chicken     tswana-chicken, tswana
  Broiler chicken    broiler
  Goat               goats, goat
  Sheep              sheep
  Cattle             cattte, cattle
  Lettuce            lettuce
  Cabbage            cabbage
  Rape               rape
  Green pepper       green-pepper
  Onions             onions, onion
  Potatoes           potatoes
  Beetroot           beetroot
  Tomatoes           tomatoes
  Watermelon         water-melon, watermelon
  Makomane           makgomane, makomane
  Maize cob          maize-cob, maize
  Chillies           chillies

To use other names, edit the "images" list for that product at the top of src/main.js.
